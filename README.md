# Jamison Agency Zip Sales Analysis

Static client reporting site for Jamison Agency (GOAL account #601), deployed on Vercel.

- `index.html`: hub with Zip Code Analysis and Lead Sources
- `Jamison-Zip-Sales-Analysis-10-16-26.html`: leads, quote rate and win rate by zip code, matched to the agency's quote and sale files
- `Jamison-Lead-Source-Analysis-10-16-26.html`: quotes and sales by source, by quarter
- `vercel.json`: clean URLs, security headers, noindex

No build step. Push to `main` and Vercel redeploys.
